So funktioniert es

  1. Wähle eine Reihe und lies jeden Tag eine Andacht.
  2. Wenn du fertig bist, tippe auf „Als gelesen markieren“.
  3. Ab dem nächsten Tag öffnet sich diese Seite automatisch bei der nächsten Andacht.
  4. Dein Fortschritt wird nur auf diesem Gerät gespeichert – nirgendwo sonst.

Tipp: Füge diese Seite zu deinem Startbildschirm hinzu. Dann funktioniert sie wie eine App – auch offline – und dein Fortschritt bleibt sicher erhalten.
